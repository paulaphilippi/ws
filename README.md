# Personal Website – Paula Philippi

Source files for my personal academic website ([paulaphilippi.github.io/ws](https://paulaphilippi.github.io/ws/)).

## Overview

- `index.html` – Main page (About, Recent Updates, Research Focus)
- `project-pages/publications.html` – Preprints, peer-reviewed publications, and preregistrations
- `project-pages/slides.html` – Invited talks, chaired symposia, and conference contributions
- `project-pages/projects.html` – Research projects (READY, STRESSY, RehaCAT+)
- `project-pages/cv.html` – CV page and embedded PDF (`assets/files/CV_PaulaPhilippi.pdf`)
- `project-pages/imprint.html` – Legal notice and privacy policy
- `css/` & `js/` – Stylesheets and filter logic

## Local Preview & Notes

To preview changes locally before committing in GitHub Desktop, open `index.html` directly in a browser. When adding new entries in `publications.html` or `slides.html`, update the item counts in the left sidebar (`toc-count` and `filter-btn`).
